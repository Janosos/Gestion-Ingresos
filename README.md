# Gestion de Ingresos

Aplicacion Flutter para la gestion de ingresos y gastos.

## Caracteristicas

- Registro de ingresos y egresos.
- Gestion de cuentas por cobrar.
- Exportacion e importacion de datos (Copia de seguridad).
- Modo claro y oscuro.
- Calculo de totales.

## Requisitos

- Flutter SDK
- Dart SDK

## Instalacion

1. Clonar el repositorio.
2. Ejecutar `flutter pub get` para instalar dependencias.
3. Ejecutar `flutter run` para iniciar la aplicacion.
